Free for BeamMP servers

Live timing and race control for your BeamNG race nights

Standings, gaps, qualifying, a held grid, flags, cautions and results files, run from one in-game app. Players get it automatically when they join your server.

Download for Windows

PRM-Setup.exe, the latest release. It finds your BeamMP server and installs Phoenix Race Manager into it.

Windows may say it does not recognise the file. Press More info, then Run anyway.

Other ways to install

Linux server

In the server's folder, run:

curl -fsSLO https://github.com/aosjay13/BeamNG-Race-Manager-by-Phoenix/releases/latest/download/PRM-Install.sh && bash PRM-Install.sh

Hosting panel with no shell

Download the release zip, upload it into the server's Resources folder and extract it there.

Already running a version with the in-game updater? The Admin tab's Update and restart installs new releases for you.

Then

  1. Start the server, or restart it if it was running.
  2. Players download PRM automatically as they join. Nobody installs anything by hand.
  3. Each driver adds Phoenix Race Manager (PRM) once from HUD Apps (search PRM), plus the optional Race Lights (PRM) and Radar (PRM).
  4. Log in on the app's admin bar with the password from the guide, then set your own.

What it does

Live timing

Running order, laps, best and last laps, and real gaps to the leader and the car ahead.

Quali to grid

Qualifying builds the grid, every car is held on its slot, and the whole field gets one countdown.

Race control

Flags, full-course cautions and restarts, a pace lap, reset limits and car locking.

Results and cups

A results file at the flag, lap records per track, and championship points across events.

More to race

Demo Derby, a drag racing ladder with a real tree, heats, joker laps and multi-class grids.

Updates in game

The server spots new releases, and an admin installs them from the Admin tab in one click.
